# POS Checkout System

A desktop point-of-sale checkout application built with C# and .NET.

## Features

- Add items to a customer's cart
- Calculate purchase totals
- Calculate tax
- Display the final amount
- Generate a receipt
- Validate user input
- Handle invalid transaction entries

## Tech Stack

- C#
- .NET
- Windows Forms
- Visual Studio

## What I Learned

This project helped me practice object-oriented programming, event-driven application development, input validation, collections, and building graphical desktop applications with C#.
